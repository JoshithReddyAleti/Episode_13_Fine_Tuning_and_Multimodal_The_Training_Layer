# Contributing to Episode 13

Thank you for wanting to improve this repo. It's part of the AI Engineering Roadmap 2026 newsletter series.

## Ways to contribute

- Fix typos and clarify explanations in the section READMEs.
- Add or improve training example recipes.
- Add utility functions that match the "tools that actually work" philosophy.
- Add tests for existing utilities.
- Suggest topics the current sections don't cover but should.

## Guidelines

1. Keep the tone direct, technically honest, non-hype.
2. Concept coverage lives in section READMEs. Code stubs are pointers, not full implementations.
3. Utility functions should actually work — real code that runs, tested, with CLI.
4. Every section README ends with a file table, forward/back navigation, and a link to the main README.
5. When adding new content, update the ROADMAP and CONCEPTS docs too.

## Pull request checklist

- [ ] Tests pass (`make test`).
- [ ] Lint passes (`make lint`).
- [ ] Documentation updated where relevant.
- [ ] Newsletter link intact.
